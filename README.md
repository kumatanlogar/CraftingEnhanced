CraftingEnhanced is a simple mod that adds new crafting recipes for vanilla items which are normally uncraftable or difficult to obtain.
Download On Modrinth: https://modrinth.com/datapack/craftingenhanced

# Custom Crafts
- Totem of Undying
- Enchanted Golden Apple
- Trident
- Beacon
- Nether Star
- Dragon Head
- Heart of the Sea
- Saddle
- Name Tag
- Bell
- Cobweb
- Chainmail Armor (full set)

# Installation
1. Download the `CraftingEnhanced` datapack ZIP file from Modrinth.
2. Place the CraftingEnhanced folder into your world's `datapacks/` directory.
3. Launch Minecraft 1.21.4 or newer, then run `/reload` in-game.
4. Verify it's loaded with `/datapack` list (should show CraftingEnhanced enabled).
